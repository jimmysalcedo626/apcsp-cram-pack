Create Performance Task — 6 Rubric Rows

📋 What Is the CPT?

The CPT is 30% of your total score. Submit your Personalized Project Reference (PPR) by April 30, 2026 — then answer two written response questions about YOUR code on exam day (May 14). Each of the 6 rows below is worth 1 point. Missing one row = losing 5 composite points (same as getting 5 fewer MCQ correct).

MCQ Attack Strategy (70 questions · 120 min)

⏱ Time Budget

~1.5–1.7 min per question. Uses College Board pseudocode only — not Java or Python. Includes single-select (4 choices) AND multi-select (pick exactly 2). No penalty for wrong answers — always answer every question.

🔥 High-Frequency MCQ Topics to Drill
  • Pseudocode tracing: loops, conditionals, list traversals
  • Binary ↔ decimal conversions
  • AND / OR / NOT truth tables
  • Linear search vs. binary search (when each is used & why)
  • Lossless vs. lossy compression (which is used where)
  • Fault tolerance: how many paths needed for connection
  • Parallel computing: speedup is NOT always n× faster
  • Privacy scenarios: what counts as PII / personal data
  • Phishing, malware, DDoS — definitions and examples
  • Beneficial vs. harmful computing impacts (nuanced both-sides answers)

Written Response Strategy (~60 min on exam day)

📝 Format

On exam day you receive a printed copy of your PPR and answer 2 written response questions (4 total prompts) about your own code. ~60 minutes. Answers must reference your specific code — generic answers earn zero points.
